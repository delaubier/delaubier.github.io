## Réalisations & Projets Techniques

### [HomeLab & Infrastructure Cloud Privée (Kubernetes / Docker)](https://github.com/delaubier/HomeLab)
* **Objectif :** Conception, déploiement et administration de bout en bout d'une infrastructure d'auto-hébergement sur du matériel reconditionné. 
* **Détails :** Mise en place d'un cluster pour orchestrer des services conteneurisés garantissant la haute disponibilité, la sécurité des données et l'automatisation de divers flux (Nextcloud, Jellyfin, Immich, écosystème Arr).
* **Stack :** Kubernetes, Docker, Linux, Administration Système.

### [LocalAI - Private & Local LLM Browser Extension](https://github.com/delaubier/LocalIA)
* **Objectif :** Développement d'une extension de navigateur permettant d'exécuter des modèles de langage de pointe (LLM) de manière 100% locale.
* **Détails :** Intégration de modèles optimisés (Llama 3.2, Qwen 2.5, Phi-3.5 Vision) sans aucune dépendance à des API externes, garantissant une confidentialité totale des données utilisateurs grâce à l'accélération matérielle (GPU) locale.
* **Stack :** WebGPU, Web-LLM, JavaScript, IA Embarquée.

### [Ligue 1 Mercato - Agent Automatisé de Veille Sportive](https://github.com/delaubier/Ligue_1_Mercato)
* **Objectif :** Création d'un agent autonome détectant et publiant en temps réel les transferts officiels de football en Ligue 1 sur X (Twitter).
* **Détails :** Conception d'un pipeline de web scraping ciblé sur Transfermarkt, avec extraction de données, formatage dynamique et publication automatisée via API, incluant une gestion stricte des doublons et des variables d'environnement.
* **Stack :** Python, Web Scraping, API Twitter, Automatisation.
